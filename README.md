# Рисовалка на GigaChat — как запустить

## Что в папке

- `index.html` — сама рисовалка.
- `api/gigachat.js` — посредник: страница обращается к нему, а он к GigaChat. Ключ хранится только на сервере.
- `vercel.json` — разрешает посреднику ждать ответа GigaChat до 60 секунд.

Без посредника не обойтись: GigaChat не принимает запросы прямо из браузера.

## 1. Ключ GigaChat

1. Зайдите на developers.sber.ru/studio и создайте проект GigaChat API (для физлиц).
2. В настройках API скопируйте **Authorization key**: длинную строку, которая часто заканчивается на `==`.
3. Scope для физлиц — `GIGACHAT_API_PERS`.

## 2. Загрузка на GitHub

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Нажмите **New repository**, придумайте имя (например, `risovalka`) и выберите Private.
3. Нажмите **uploading an existing file** и перетащите всё содержимое папки, включая папку `api`. Затем нажмите Commit.

## 3. Публикация на Vercel (бесплатно)

1. Зайдите на vercel.com и войдите через GitHub.
2. Нажмите **Add New → Project**, выберите репозиторий `risovalka` и затем **Import**.
3. Перед нажатием Deploy раскройте **Environment Variables** и добавьте:

   | Имя | Значение |
   |---|---|
   | `GIGACHAT_AUTH_KEY` | ваш Authorization key |
   | `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` |
   | `APP_PASSWORD` | любой пароль, например `kotik2026` |
   | `GIGACHAT_MODEL` | `GigaChat` (можно не задавать) |

4. Нажмите **Deploy**. Через минуту появится ссылка вида `risovalka-xxx.vercel.app`.

Если переменные добавлены или изменены уже после первого деплоя, откройте **Deployments**, нажмите **⋯** у последнего деплоя и выберите **Redeploy**.

## 4. Первый запуск

1. Откройте ссылку в Chrome или Edge.
2. Нажмите ⚙ и введите пароль из `APP_PASSWORD`. Он запомнится в этом браузере.
3. Нажмите на микрофон или пробел, скажите «красная собака» и разрешите доступ к микрофону.
4. Для ребёнка разверните окно на весь экран клавишей F11.

## Управление

- Короткое нажатие на микрофон или пробел: программа слушает до паузы.
- Удержание дольше полсекунды: программа слушает, пока кнопку не отпустят.
- Повторное нажатие во время прослушивания останавливает запись.
- Голосом можно сказать: «а рядом кошка», «сделай собаку больше», «перекрась кошку в синий», «убери солнце», «отмени», «новый лист».
- Кнопка «⌨ Словами» позволяет писать текстом вместо голоса.

## Если не работает

- **«Сервер не достучался до GigaChat».** Возможно, GigaChat не отвечает на запросы с серверов Vercel, которые находятся за пределами РФ. Посмотрите логи в Vercel: Project → Logs. Если там ошибки соединения, нужен посредник на российском хостинге или на домашнем компьютере.
- **«GigaChat не принял ключ».** Проверьте `GIGACHAT_AUTH_KEY` (без пробелов и кавычек) и `GIGACHAT_SCOPE`, затем сделайте Redeploy.
- **«Неверный пароль».** Пароль в ⚙ должен совпадать с `APP_PASSWORD`.
- **Сертификат.** По умолчанию посредник не проверяет сертификат серверов GigaChat, потому что Node.js не знает корневой сертификат Минцифры. Чтобы проверка была строгой, скачайте сертификат «Russian Trusted Root CA» с сайта Сбера (инструкция: developers.sber.ru/docs/ru/gigachat/certificates) и вставьте содержимое PEM-файла целиком в переменную `GIGACHAT_CA_CERT`.
- **Микрофон.** Работает в Chrome и Edge, нужен интернет. Если доступ запрещён, нажмите на значок замка слева от адреса и выберите «Микрофон → Разрешить».
